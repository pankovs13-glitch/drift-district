# Drift District

3D arcade drifting prototype on **Godot 4.3+**, targeting a future Yandex Games Web release.

## v0.2 — rear-wheel-drive physics prototype

- RWD power oversteer: adding throttle while turning can break rear traction
- Handbrake drifting, countersteering, yaw inertia
- Procedurally generated car, training arena, follow camera
- Drift angle / speed / scoring HUD and touch controls
- Compatibility renderer for future browser export

## Run

1. Download or clone this repository.
2. Open `project.godot` in Godot 4.3+.
3. Press **F5**.

**W/↑** gas, **S/↓** brake, **A/D or ←/→** steer, **Space** handbrake, **R** reset car.

> Early prototype. Physics needs playtesting and tuning. Yandex Games SDK/export is not implemented yet.
